
# Lokta Borrower Copilot

Lokta Borrower Copilot is a **Java Spring Boot application** that helps Indian borrowers make safer and more informed loan decisions.

### Key Features

* Recommends **Borrow, Borrow Less, or Don't Borrow**
* Separates **lender eligibility** from **borrower-safe amount**
* Estimates a **fair interest-rate range and borrowing cost**
* Calculates **EMI and affordable EMI ceiling**
* Provides **stress-case analysis**
* Generates a **Negotiation Card** that borrowers can use when discussing loan terms with lenders

### Technology

* Java 17
* Spring Boot
* Thymeleaf
* HTML, CSS, JavaScript
* Maven
* JUnit

### Goal

The project shifts the question from:

**"How much will the lender give me?"**

to:

**"How much can I safely borrow, what should it cost, and what should I negotiate?"**
